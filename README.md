# Eight-vertex paper tori

The verification code accompanying *The two most symmetric flat tori as
eight-vertex paper tori*, by Fabian Lander.

    python3 verify.py

Python 3, no dependencies, a second or two. Everything is exact, rationals for
the square torus and `a + b*sqrt3` for the hexagonal one, and the run exits
nonzero if any check fails.
